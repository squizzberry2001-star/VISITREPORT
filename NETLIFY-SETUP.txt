Tutorial singkat setup database Netlify untuk Bestie Visit

File konfigurasi Netlify yang wajib ada di root project:
- netlify.toml
- netlify-config.js
- package.json
- package-lock.json
- netlify/functions/rbv-data.mjs

Cara deploy:
1. Upload seluruh isi ZIP ini ke root site Netlify kamu.
2. Pastikan folder netlify/functions tetap ada, jangan dipindah.
3. Redeploy Netlify.
4. Test endpoint:
   https://domain-kamu.netlify.app/.netlify/functions/rbv-data?action=listAppSettings
   Jika muncul JSON {"ok":true,...}, function Netlify sudah aktif.

Setting URL function di frontend:
- Buka netlify-config.js.
- Untuk domain yang sama, baseUrl boleh dikosongkan atau pakai domain site kamu.
- functionPath tetap mengarah ke /.netlify/functions/rbv-data.

Opsional security admin:
- Di Netlify dashboard > Site configuration > Environment variables, buat RBV_ADMIN_TOKEN.
- Kalau token diaktifkan, isi token yang sama di netlify-config.js bagian adminToken.
- Catatan: token di frontend bukan rahasia penuh, ini hanya pengaman dasar.
